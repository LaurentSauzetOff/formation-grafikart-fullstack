# 🔥 Philosophie pédagogique

Je privilégie une approche orientée :

## 1. Fondamentaux solides

Chaque technologie est revue avec rigueur afin de :

- corriger d'éventuelles mauvaises habitudes
- consolider les bases
- approfondir les subtilités

---

## 2. Mise en pratique immédiate

Chaque cours donne lieu à :

- exercices
- expérimentations
- mini projets
- travaux pratiques

---

## 3. Progression continue

Les projets ne sont pas abandonnés après un cours.

Ils évoluent progressivement :

```txt
HTML → CSS → JavaScript → Backend → Database → DevOps
```

Chaque nouvelle compétence vient enrichir l'existant.
